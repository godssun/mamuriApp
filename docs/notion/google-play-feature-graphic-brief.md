# Google Play Feature Graphic 디자인 브리프

> 최종 업데이트: 2026-03-23
> 상태: 🔴 미제작 — Google Play 제출 필수 에셋
> 사양: 1024 × 500px, PNG 또는 JPEG (알파 없음)

---

## 1. Feature Graphic이란?

Google Play에서 앱 검색 결과 상단 또는 스토어 페이지 상단에 표시되는 배너 이미지입니다.
사용자가 앱을 설치할지 결정하는 **첫인상**에 해당하므로, 브랜딩과 메시지 전달이 매우 중요합니다.

### 표시 위치

```
┌─────────────────────────────────┐
│  [Feature Graphic 1024×500]     │  ← Google Play 스토어 상단
│  앱의 첫인상 / 브랜딩 배너      │
├─────────────────────────────────┤
│  앱 아이콘 | 앱 이름 | 설치 버튼 │
├─────────────────────────────────┤
│  스크린샷 슬라이드                │
└─────────────────────────────────┘
```

### 기술 사양

| 항목 | 값 |
|------|-----|
| 크기 | **1024 × 500px** (가로 × 세로) |
| 형식 | PNG 또는 JPEG |
| 알파 채널 | **불가** (투명 배경 사용 불가) |
| Safe Zone (텍스트 배치) | 중앙 80% 영역 (양쪽 여백 ~100px) |
| 모바일 표시 크기 | 약 360 × 176px로 축소됨 |
| 오버레이 | Google Play가 하단에 재생 버튼(동영상 있을 때)이나 그라데이션을 오버레이할 수 있음 |

## 3. 메시지 방향 3가지

### 메시지 A: "하루의 끝, 따뜻한 AI 친구" — ★ 최종 권장

| 항목 | 내용 |
|------|------|
| 핵심 메시지 | 하루를 마무리하는 순간의 따뜻함 |
| 감정 | 안도, 편안함, 위로 |
| 타겟 감정 유발 | "이 앱이면 하루 끝에 마음이 편해지겠다" |
| 텍스트 | **마무리** (로고) + "하루의 끝, 따뜻한 AI 친구" |

**이 방향이 좋은 이유**:
- 앱 이름 "마무리"의 의미를 직접 전달
- "AI 친구"로 차별화 포인트 명확
- "따뜻한"으로 감정적 톤 설정
- 짧고 기억에 남음

### 메시지 B: "일기를 쓰면, 친구가 답장해요"

| 항목 | 내용 |
|------|------|
| 핵심 메시지 | 핵심 기능 직접 설명 |
| 감정 | 호기심, 기대감 |
| 타겟 감정 유발 | "일기를 쓰면 답장이 온다고? 해보고 싶다" |
| 텍스트 | **마무리** (로고) + "일기를 쓰면, 친구가 답장해요" |

### 메시지 C: "오늘 하루, 어떠셨나요?"

| 항목 | 내용 |
|------|------|
| 핵심 메시지 | 사용자에게 직접 말 걸기 |
| 감정 | 공감, 관심, 친근함 |
| 타겟 감정 유발 | "누군가 나한테 관심을 가져주는 느낌" |
| 텍스트 | **마무리** (로고) + "오늘 하루, 어떠셨나요?" |

## 4. 레이아웃 컨셉 3가지

### 레이아웃 1: "중앙 집중형" — ★ 최종 권장

```
┌──────────────────────────────────────────────┐
│                                              │
│                                              │
│              [앱 아이콘 120×120]              │
│              마 무 리                         │
│       하루의 끝, 따뜻한 AI 친구               │
│                                              │
│                                              │
│     배경: Indigo→Lavender 대각선 그라데이션    │
└──────────────────────────────────────────────┘
```

| 요소 | 상세 |
|------|------|
| 배경 | `#6356D9` → `#9488FF` 좌하→우상 대각선 그라데이션 |
| 앱 아이콘 | 중앙 상단, 120×120px 정도 |
| 앱 이름 | "마무리" — 큰 폰트(Bold), White (#FFFFFF) |
| 서브 텍스트 | "하루의 끝, 따뜻한 AI 친구" — 작은 폰트(Regular), White 80% |
| 장식 | 배경에 미세한 빛점/별 패턴 (선택사항) |
| 폰트 | Pretendard Bold / Noto Sans KR Bold |

**장점**: 가장 깔끔하고 프리미엄. 축소해도 읽기 쉬움.

---

### 레이아웃 2: "좌우 분할형"

```
┌──────────────────────────────────────────────┐
│                              │               │
│   [앱 아이콘]                │  [앱 스크린샷  │
│   마 무 리                   │   모크업]      │
│   하루의 끝,                 │               │
│   따뜻한 AI 친구             │               │
│                              │               │
│   배경: Indigo 그라데이션     │               │
└──────────────────────────────────────────────┘
```

| 요소 | 상세 |
|------|------|
| 좌측 60% | 앱 아이콘 + 텍스트 |
| 우측 40% | 앱 스크린샷(일기 상세) 기울어진 모크업 |
| 배경 | 좌: `#6356D9` 그라데이션, 우: 약간 밝아지며 스크린샷 |

**장점**: 앱 화면을 직접 보여줌
**단점**: 요소가 많아 축소 시 복잡해 보일 수 있음

---

### 레이아웃 3: "감정 컬러 배경형"

```
┌──────────────────────────────────────────────┐
│  ○ ○ ○ ○ ○ ○ ○ ○                            │
│  (감정 컬러 원형 아이콘들)                     │
│                                              │
│         마 무 리                              │
│   오늘의 감정을 기록하세요                      │
│                                              │
│   배경: Warm White + 감정 컬러 장식             │
└──────────────────────────────────────────────┘
```

| 요소 | 상세 |
|------|------|
| 배경 | `#FAFAF8` (Warm White) |
| 장식 | 8가지 감정 컬러 원형 (Happy, Calm, Sad, Anxious...) |
| 텍스트 | "마무리" (Indigo), 서브 텍스트 (Dark Gray) |

**장점**: 감정 기록 기능 강조, 밝고 접근하기 쉬운 느낌
**단점**: 앱 아이콘이 Indigo 계열이면 배경과 조화가 약할 수 있음

## 5. 최종 권장 조합

| 항목 | 선택 |
|------|------|
| 메시지 | **A: "하루의 끝, 따뜻한 AI 친구"** |
| 레이아웃 | **1: 중앙 집중형** |

### 최종 디자인 사양

```
크기: 1024 × 500px
형식: PNG (24-bit, 알파 없음)

배경:
  - 색상: #6356D9 → #9488FF 대각선 그라데이션 (좌하→우상)
  - 장식: 미세한 빛점/별 3-5개 (opacity 15-25%, 크기 4-8px)
  - 질감: 미세한 노이즈 텍스처 (2-3%, 선택사항)

앱 아이콘:
  - 위치: 중앙, 상단에서 120px 지점
  - 크기: 100-120px
  - 그림자: 부드러운 drop shadow (0, 4, 16, rgba(0,0,0,0.15))

메인 텍스트 "마무리":
  - 위치: 아이콘 바로 아래, 중앙 정렬
  - 폰트: Pretendard Bold (또는 Noto Sans KR Bold)
  - 크기: 64-72px
  - 색상: #FFFFFF
  - 자간: 4-8px (약간 넓게)

서브 텍스트 "하루의 끝, 따뜻한 AI 친구":
  - 위치: 메인 텍스트 아래 16px
  - 폰트: Pretendard Regular (또는 Noto Sans KR Regular)
  - 크기: 28-32px
  - 색상: rgba(255,255,255,0.8)
  - 자간: 1-2px

Safe Zone:
  - 모든 텍스트와 아이콘은 가로 100px, 세로 60px 안쪽에 배치
```

## 6. 다국어 대응

Feature Graphic은 스토어 언어 설정에 따라 다른 버전을 업로드할 수 있습니다.

| 언어 | 메인 텍스트 | 서브 텍스트 |
|------|-----------|-----------|
| ko | 마무리 | 하루의 끝, 따뜻한 AI 친구 |
| en | Mamuri | End your day with a warm AI friend |
| ja | マムリ | 一日の終わりに、温かいAI友達 |
| zh | Mamuri | 用温暖的AI朋友结束一天 |

> MVP 시: 한국어 1장만으로도 충분합니다. 나중에 언어별 버전 추가 가능.

## 7. 피해야 할 Feature Graphic 디자인

| 피해야 할 것 | 이유 |
|-------------|------|
| 텍스트가 너무 많은 디자인 | 축소 시 읽기 어려움 |
| 스크린샷만으로 채운 디자인 | 브랜딩 약화, 스토어 페이지 스크린샷과 중복 |
| 흰색/밝은 배경 | Google Play 배경과 구분 안 됨, 임팩트 약함 |
| 작은 텍스트 (20px 이하) | 모바일에서 축소 시 완전히 안 보임 |
| 가격/할인 정보 | Google Play 정책 위반 가능 |
| "무료" 강조 | 정책 위반 위험 |
| 수상 배지/평점 | 정책 위반 가능 |
| 너무 화려한 그라데이션 | 저급해 보일 수 있음 |
| 검은색 배경 | 무겁고 어두운 느낌, 앱 톤과 불일치 |
| 사진/실사 배경 | 깔끔하지 않고, 브랜딩 약화 |
| 핵심 요소를 하단 중앙에 배치 | Google Play 오버레이(재생 버튼)와 겹칠 수 있음 |

## 8. 제작 가이드

### 방법 1: Figma (권장)

```
1. Figma에서 1024×500 프레임 생성
2. 배경: Linear Gradient (135°, #6356D9 → #9488FF)
3. 앱 아이콘 배치 (중앙 상단)
4. "마무리" 텍스트 추가 (Pretendard Bold 68px, White)
5. 서브 텍스트 추가 (Pretendard Regular 30px, White 80%)
6. 빛점 장식 추가 (Ellipse, #FFEFC4, Opacity 20%, Blur 4)
7. Export as PNG, 1x scale
```

### 방법 2: Canva

```
1. Custom size: 1024×500
2. Background: Gradient (Purple/Lavender)
3. Upload app icon → center top
4. Add text: "마무리" (Bold, White, Large)
5. Add text: "하루의 끝, 따뜻한 AI 친구" (Regular, White, Medium)
6. Download as PNG
```

### 방법 3: AI 이미지 생성 (Midjourney/DALL-E)

```
A Google Play feature graphic banner, 1024x500 pixels. Minimal and premium
design. Deep indigo (#6356D9) to lavender (#9488FF) diagonal gradient
background with subtle light dot decorations. Center-aligned layout with
a small app icon (crescent moon in amber), Korean text "마무리" in large
white bold font below, and subtitle "하루의 끝, 따뜻한 AI 친구" in smaller
white text. Clean, warm, calming feel. No photos, no clutter. Flat design.
```

> AI로 생성한 이미지는 한글 렌더링이 부정확할 수 있으므로, 배경만 AI로 생성하고
> 텍스트는 Figma/Canva에서 직접 올리는 것을 권장합니다.
