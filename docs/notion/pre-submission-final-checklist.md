## ✅ 기능별 QA 체크리스트

### 1. 백엔드 / API

- [ ] `https://api.mamuri.app/actuator/health` → 200 OK ✅ (확인됨)
- [ ] AI Provider가 `openai`로 설정되어 있는지 확인 (stub 아님)
- [ ] JWT 토큰 발급/갱신/만료 정상 동작
- [ ] Rate limiting 동작 확인
- [ ] DB 마이그레이션 전부 적용 확인 (V1-V19)
- [ ] CORS 설정에 모바일 앱 요청 허용 확인
- [ ] 에러 응답 형식 일관성 확인 (success/data/message)

### 2. 로그인 / 인증

- [ ] **이메일 회원가입**: 새 계정 생성 → 닉네임 설정 → 메인 화면
- [ ] **이메일 로그인**: 기존 계정 → 정상 로그인
- [ ] **잘못된 비밀번호**: 적절한 에러 메시지 표시
- [ ] **Google 로그인**: Google 인증 → Firebase → 백엔드 토큰
- [ ] **Apple 로그인** (iOS): Apple 인증 → Firebase → 백엔드 토큰
- [ ] **소셜 첫 로그인**: 닉네임 설정 화면으로 이동
- [ ] **소셜 재로그인**: 바로 메인 화면으로 이동
- [ ] **토큰 만료**: 자동 갱신 → 사용자 경험 끊김 없음
- [ ] **강제 로그아웃**: 토큰 재사용 감지 시 로그아웃
- [ ] **로그아웃**: 설정에서 로그아웃 → 로그인 화면

### 3. 일기 기능

- [ ] **일기 작성**: 제목 + 내용 + 감정 선택 → 저장
- [ ] **일기 목록**: 날짜순 정렬, 캘린더 뷰 동작
- [ ] **일기 상세**: 내용 표시 + AI 답변 표시
- [ ] **일기 수정**: 내용 변경 → 저장
- [ ] **일기 삭제**: 삭제 확인 → 목록에서 제거
- [ ] **빈 일기 방지**: 내용 없이 저장 시 에러 메시지
- [ ] **긴 일기**: 3000자 이상 입력 시 적절한 처리

### 4. AI 댓글 / AI 대화

- [ ] **AI 동의 모달**: 첫 일기 작성 시 AI 데이터 동의 모달 표시
- [ ] **동의 후 AI 응답**: 일기 저장 후 AI 답변 생성 확인
- [ ] **AI 응답 품질**: 한국어로 공감적, 따뜻한 톤인지 확인
- [ ] **AI 응답 길이**: 2-5문장 이내인지 확인
- [ ] **AI 대화**: AI 답변에 추가 대화 가능한지 확인
- [ ] **AI 실패 시**: AI 호출 실패해도 일기는 저장됨 확인
- [ ] **AI 재시도**: AI 실패 후 재시도 버튼 동작
- [ ] **AI 응답 신고**: 신고 모달 → 이유 선택 → 제출 성공
- [ ] **위기 감지**: 위기 키워드 포함 일기 → 안전 메시지 + 핫라인 번호

### 5. AI 친구 (Companion)

- [ ] **프로필 확인**: AI 친구 이름, 성격, 말투 표시
- [ ] **이름 변경**: AI 친구 이름 변경 → 저장
- [ ] **성격 설정**: 4가지 톤 중 선택 → AI 응답에 반영
- [ ] **말투 설정**: 존댓말/반말 선택 → AI 응답에 반영
- [ ] **아바타 업로드**: 사진 선택 → 업로드 → 표시
- [ ] **아바타 삭제**: 기본 아바타로 복원
- [ ] **연속 기록 (Streak)**: 연속 일기 작성 카운트 정상

### 6. 계정 삭제

- [ ] **삭제 시작**: 설정 → 계정 삭제 버튼
- [ ] **1단계 경고**: 삭제될 데이터 목록 표시
- [ ] **2단계 이유**: 6가지 이유 + 기타(상세 입력) 선택
- [ ] **3단계 확인 (이메일)**: 비밀번호 입력 → 삭제 완료
- [ ] **3단계 확인 (소셜)**: 확인 텍스트 입력 → 삭제 완료
- [ ] **삭제 후**: 로그인 화면으로 이동
- [ ] **삭제 계정 재로그인**: 해당 계정으로 로그인 불가 확인
- [ ] **데이터 삭제 확인**: 일기, AI 답변, 대화 모두 삭제됨

### 7. 설정

- [ ] **프로필 표시**: 닉네임, 이메일 정상 표시
- [ ] **다크 모드**: 테마 전환 → 전체 앱 다크/라이트 정상
