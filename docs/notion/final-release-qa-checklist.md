## 1. 백엔드 / API 검증

### 1.1 서버 상태
- [ ] `https://api.mamuri.app/actuator/health` 응답 확인 (200 OK)
- [ ] SSL 인증서 유효 (만료일 확인)
- [ ] API 응답 시간 < 500ms (주요 엔드포인트)
- [ ] 데이터베이스 연결 정상

### 1.2 인증 API
- [ ] `POST /api/auth/signup` — 회원가입 정상
- [ ] `POST /api/auth/login` — 로그인 정상
- [ ] `POST /api/auth/refresh` — 토큰 갱신 정상
- [ ] `POST /api/auth/logout` — 로그아웃 정상
- [ ] `POST /api/auth/social` — 소셜 로그인 정상
- [ ] 만료된 토큰으로 요청 시 401 응답
- [ ] 잘못된 비밀번호 시 400 응답 (401이 아닌 것 확인)

### 1.3 일기 API
- [ ] `POST /api/diaries` — 일기 생성 + AI 코멘트 자동 생성
- [ ] `GET /api/diaries` — 일기 목록 조회
- [ ] `GET /api/diaries/{id}` — 일기 상세 조회
- [ ] `PUT /api/diaries/{id}` — 일기 수정
- [ ] `DELETE /api/diaries/{id}` — 일기 삭제
- [ ] AI 코멘트 생성 실패 시에도 일기 저장 확인

### 1.4 대화 API
- [ ] `GET /api/conversations/{diaryId}` — 대화 기록 조회
- [ ] `POST /api/conversations/{diaryId}/reply` — AI 답변 생성
- [ ] 일일 답변 횟수 제한 동작 확인
- [ ] 대화 제한 초과 시 적절한 에러 응답

### 1.5 계정 관리 API
- [ ] `DELETE /api/account` — 이메일 유저 계정 삭제 (비밀번호 필요)
- [ ] `DELETE /api/account` — 소셜 유저 계정 삭제 (비밀번호 불필요)
- [ ] 계정 삭제 시 관련 데이터 CASCADE 삭제 확인

### 1.6 Rate Limiting
- [ ] 로그인 실패 반복 시 Rate Limit 동작
- [ ] 일반 API 호출 Rate Limit 동작

## 7. 에러 처리 / 크래시 검증

### 7.1 네트워크 에러
- [ ] 비행기 모드에서 앱 실행 → 크래시 없음
- [ ] API 호출 중 네트워크 끊김 → 에러 메시지 표시
- [ ] 네트워크 복구 후 정상 동작
- [ ] 느린 네트워크 (3G) → 로딩 표시, 타임아웃 처리

### 7.2 앱 생명주기
- [ ] 백그라운드 → 포그라운드 전환 시 정상
- [ ] 앱 강제 종료 후 재시작 정상
- [ ] 메모리 부족 시 크래시 없음 (가능한 범위 내)
- [ ] 화면 전환 중 빠른 터치 → 크래시 없음

### 7.3 입력 검증
- [ ] 초긴 텍스트 입력 (5000자+) → 적절히 처리
- [ ] 특수문자/이모지 입력 → 정상 처리
- [ ] 빈 입력 → 유효성 검사 동작
- [ ] HTML/스크립트 태그 입력 → 인젝션 없음

### 7.4 Edge Cases
- [ ] 동시에 여러 일기 저장 시도 → 정상 처리
- [ ] 삭제된 일기의 AI 대화 접근 시 → 적절한 에러
- [ ] 토큰 만료 중 여러 API 동시 호출 → 정상 갱신
