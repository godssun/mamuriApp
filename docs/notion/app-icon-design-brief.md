## 3. 아이콘 컨셉 방향 3가지

### 방향 A: "마무리 달" (Closing Moon) — ★ 최종 권장

**컨셉**: 초승달/반달 형태 안에 작은 빛(별 또는 반딧불이)

**감정적 톤**:
- 하루의 끝, 밤의 고요함
- "마무리"의 시간적 의미 — 저녁, 달, 마무리하는 시간
- 따뜻하고 안전한 느낌

**시각적 디테일**:
```
┌─────────────────────┐
│                     │
│     ╭━━╮            │
│    ╭╯  ╰╮           │
│   │  ✦   │          │
│   │      │          │
│    ╰╮  ╭╯           │
│     ╰━━╯            │
│                     │
│  배경: Indigo→Lavender │
│  달: Amber/Gold 계열   │
│  빛: Amber 하이라이트   │
│                     │
└─────────────────────┘
```

| 요소 | 상세 |
|------|------|
| 형태 | 둥근 사각형(squircle) 안에 초승달 + 작은 빛점 |
| 배경 | `#6356D9` → `#9488FF` 대각선 그라데이션 |
| 달 | `#FFD876` → `#FFEFC4` 그라데이션 (Amber 계열) |
| 빛점 | `#FFEFC4` 반투명 글로우 1-2개 |
| 스타일 | 미니멀, 라운드 에지, 플랫 디자인 |
| 참고 앱 | Calm (단순 형태 + 그라데이션), Headspace (둥근 + 따뜻한) |

**이 방향이 좋은 이유**:
- "마무리" = 하루의 끝 = 달/밤 → 앱 이름과 직접 연결
- 인디고 배경 + 앰버 달 = 앱 컬러 시스템 그대로 반영
- 심플하고 작은 크기에서도 식별 가능
- 경쟁 앱(Reflectly, Day One 등)과 차별화

---

### 방향 B: "대화 풍선 하트" (Warm Reply)

**컨셉**: 말풍선 안에 하트 또는 따뜻한 무늬

**감정적 톤**:
- AI "친구"가 답장하는 핵심 경험
- 대화, 공감, 답장의 따뜻함

**시각적 디테일**:
```
┌─────────────────────┐
│                     │
│      ╭──────╮       │
│      │  ♡   │       │
│      ╰──┬───╯       │
│         ╰           │
│                     │
│  배경: Warm White     │
│  풍선: Indigo         │
│  하트: Amber/Rose     │
│                     │
└─────────────────────┘
```

| 요소 | 상세 |
|------|------|
| 형태 | 둥근 말풍선 + 내부 하트/글로우 |
| 배경 | `#FAFAF8` 또는 `#F0EEFF` |
| 말풍선 | `#6356D9` (Primary Indigo) |
| 하트 | `#D9B34A` (Amber) 또는 `#D95A55` (Rose) |
| 스타일 | 미니멀, 둥근 모서리 |

**장점**: AI "답장" 기능을 직접적으로 표현
**단점**: 메시지 앱으로 오해될 수 있음, 일기 앱 정체성 약화

---

### 방향 C: "펜과 빛" (Journaling Light)

**컨셉**: 기울어진 펜/연필 위에 따뜻한 빛이 감싸는 형태

**감정적 톤**:
- 글쓰기, 기록하기
- 글에서 따뜻한 빛이 나오는 느낌

**시각적 디테일**:
```
┌─────────────────────┐
│                     │
│      ╱              │
│     ╱ ✦ (빛 방사)   │
│    ╱                │
│   ╱                 │
│                     │
│  배경: Indigo 그라데이션│
│  펜: White/Cream      │
│  빛: Amber 글로우      │
│                     │
└─────────────────────┘
```

| 요소 | 상세 |
|------|------|
| 형태 | 45도 기울어진 미니멀 펜 + 빛 효과 |
| 배경 | `#6356D9` → `#4E43B0` 그라데이션 |
| 펜 | White 또는 `#FFEFC4` |
| 빛 | `#FFD876` 방사형 글로우 |
| 스타일 | 미니멀, 기하학적 |

**장점**: "일기" 정체성 명확
**단점**: 펜 아이콘은 노트/메모 앱과 혼동될 수 있음, Day One/Journey와 유사

## 6. 제작 사양

### 필요한 파일

| 용도 | 파일 | 크기 | 형식 |
|------|------|------|------|
| iOS App Store | icon.png | 1024 × 1024 | PNG (RGB, 알파 없음) |
| Android Adaptive (전경) | adaptive-icon.png | 1024 × 1024 | PNG (알파 포함 가능) |
| Android Adaptive (배경) | adaptive-background.png | 1024 × 1024 | PNG 또는 단색 지정 |
| Google Play 스토어 | play-store-icon.png | 512 × 512 | PNG (32-bit, 알파 포함) |
| 스플래시 화면 | splash-icon.png | 1024 × 1024 | PNG |
| 웹 파비콘 | favicon.png | 48 × 48 | PNG |

### iOS 아이콘 규칙

- 알파 채널(투명) **불가** — 완전 불투명 필수
- iOS가 자동으로 둥근 모서리 적용 — 직접 둥글리지 말 것
- 그림자/글로우 효과는 아이콘 내부에서만 (외부 그림자 불가)
- 아이콘 테두리선 추가하지 말 것 (iOS 자동 처리)

### Android Adaptive Icon 규칙

- 전경(foreground): 아이콘 요소만, 배경 투명 가능
- 배경(background): 단색 또는 그라데이션
- 안전 영역: 중앙 66% (72dp/108dp 기준)
- 원형/사각형/둥근사각형/찌그러진원 등 다양한 마스크 대응
- 핵심 요소는 반드시 안전 영역 내에 배치

### 안전 영역 가이드 (Adaptive Icon)

```
┌──────────────────────────┐  1024 × 1024
│                          │
│    ┌──────────────┐      │
│    │              │      │
│    │  안전 영역    │      │
│    │  (66% = 676) │      │
│    │              │      │
│    │  핵심 요소는   │      │
│    │  여기에만 배치  │      │
│    │              │      │
│    └──────────────┘      │
│                          │
│   여백: 각 방향 174px     │
│                          │
└──────────────────────────┘
```

### AI 이미지 생성 프롬프트 (Midjourney/DALL-E용)

방향 A "마무리 달" 기준:

```
A minimal, modern app icon design. A crescent moon shape in warm amber gold
(#FFD876) floating on a deep indigo-to-lavender gradient background
(#6356D9 to #9488FF). One or two small glowing light dots near the moon
in soft amber (#FFEFC4). Flat design, rounded aesthetic, no text, no
outlines. Premium feel, warm and calming. iOS app icon style, 1024x1024px.
Clean vector look, no realistic textures.
```

```
미니멀하고 모던한 앱 아이콘. 깊은 인디고에서 라벤더로 이어지는 그라데이션 배경 위에
따뜻한 앰버 골드색 초승달. 달 근처에 부드러운 앰버색 빛점 1-2개. 플랫 디자인,
둥근 미학, 텍스트 없음. 프리미엄하고 차분한 느낌. iOS 앱 아이콘 스타일.
```
