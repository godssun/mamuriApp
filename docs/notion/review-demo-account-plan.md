# 심사용 데모 계정 계획

> 최종 업데이트: 2026-03-23
> 목적: Apple App Store 및 Google Play Store 심사관이 앱 기능을 테스트할 수 있도록 준비

---

## 1. 계정 전략

### 권장: 단일 공유 계정

| 항목 | 결정 |
|------|------|
| 계정 수 | **1개** (양쪽 스토어 공유) |
| 이메일 | reviewer@mamuri.app |
| 비밀번호 | Review2026! (또는 유사한 기억하기 쉬운 비밀번호) |
| 생성 위치 | 프로덕션 서버 (https://api.mamuri.app) |
| 생성 방법 | 앱에서 직접 회원가입 또는 API 호출 |

### 단일 계정으로 충분한 이유

- Apple과 Google 심사는 동시에 진행되지 않음 (제출 시점이 다름)
- 심사관은 읽기 위주 테스트를 하며, 계정 상태를 크게 변경하지 않음
- 만약 한쪽 심사관이 계정을 삭제하면 재생성하면 됨
- 소셜 로그인 테스트는 심사관 자체 Google/Apple 계정으로 진행

### 대안: 분리 계정 (필요 시)

| 스토어 | 이메일 | 비밀번호 |
|--------|--------|----------|
| Apple | apple-reviewer@mamuri.app | AppleReview2026! |
| Google | google-reviewer@mamuri.app | GoogleReview2026! |

> 분리가 필요한 경우: 양쪽 스토어에 동시에 제출하고, 한쪽 심사관이 계정 삭제를 테스트할 가능성이 높을 때

## 2. 사전 로드할 샘플 데이터

### 일기 엔트리 (5개)

심사관이 로그인 직후 바로 기능을 확인할 수 있도록 다양한 시나리오의 일기를 미리 작성합니다.

| # | 날짜 | 제목 | 감정 | 내용 (요약) | AI 답변 여부 |
|---|------|------|------|-------------|-------------|
| 1 | 오늘 | 좋은 하루였어요 | 행복 | 오늘 날씨가 좋아서 산책했어요. 커피도 마시고 기분이 좋았어요. | ✅ AI 답변 있음 |
| 2 | 어제 | 조금 피곤한 날 | 지침 | 회의가 많았던 하루. 저녁에 좀 쉬고 싶어요. | ✅ AI 답변 있음 |
| 3 | 3일 전 | 감사한 순간 | 감사 | 오랜만에 친구를 만났어요. 서로 이야기 나누며 시간 가는 줄 몰랐어요. | ✅ AI 답변 있음 |
| 4 | 5일 전 | 새로운 시작 | 설렘 | 새로운 프로젝트를 시작했어요. 잘 해낼 수 있을까 기대되면서도 긴장돼요. | ✅ AI 답변 + 대화 1-2턴 |
| 5 | 7일 전 | 비 오는 날 | 평온 | 비 소리를 들으며 차를 마셨어요. 조용한 시간이 좋았어요. | ✅ AI 답변 있음 |

### 일기 내용 예시 (전체 텍스트)

#### 일기 #1: 좋은 하루였어요
```
오늘은 날씨가 정말 좋았어요. 점심 먹고 회사 근처 공원에서 산책했는데,
벚꽃이 피기 시작했더라구요. 따뜻한 바람이 불어서 기분이 좋았어요.
퇴근하고 좋아하는 카페에서 아이스 아메리카노를 마시면서
오늘 하루를 돌아봤어요. 소소하지만 행복한 하루였어요.
```

#### 일기 #2: 조금 피곤한 날
```
오늘은 아침부터 회의가 세 개나 있었어요.
점심도 제대로 못 먹고 오후까지 미팅이 계속됐어요.
집에 오니까 아무것도 하고 싶지 않더라구요.
그냥 소파에 누워서 멍하니 있었어요. 내일은 좀 여유로웠으면 좋겠어요.
```

#### 일기 #3: 감사한 순간
```
오랜만에 대학 동기를 만났어요. 2년 만이었는데
만나자마자 예전처럼 편하게 이야기할 수 있었어요.
서로 근황도 나누고, 옛날 추억도 이야기하며 많이 웃었어요.
좋은 사람이 곁에 있다는 게 참 감사한 일이에요.
```

#### 일기 #4: 새로운 시작
```
오늘부터 새로운 프로젝트에 투입됐어요.
처음 해보는 분야라서 긴장도 되고, 한편으로는 설레기도 해요.
팀원들도 좋은 것 같고, 열심히 배워보려구요.
잘 해낼 수 있겠죠? 나 자신을 믿어봐야겠어요.
```

#### 일기 #5: 비 오는 날
```
하루 종일 비가 왔어요. 창문을 열어놓고 비 소리를 들었어요.
따뜻한 차를 한 잔 내려 마시면서 책을 읽었어요.
아무 약속 없이 혼자만의 시간을 보내는 게 이렇게 좋을 줄 몰랐어요.
가끔은 이렇게 조용한 하루도 필요한 것 같아요.
```

## 3. 데모 계정 생성 절차

### 방법 A: 앱에서 직접 가입 (권장)

```
1. 프로덕션 빌드 앱 설치 (EAS Build → TestFlight 또는 실기기)
2. 회원가입 화면에서:
   - 이메일: reviewer@mamuri.app
   - 비밀번호: Review2026!
   - 닉네임: 리뷰어
   - AI 동의 체크박스: 체크
3. AI 친구 설정: 기본값 유지 (마음이, 따뜻한, 존댓말)
4. 일기 5개 순서대로 작성 (위 내용 복사-붙여넣기)
5. 각 일기 저장 후 AI 답변 생성 확인
6. 일기 #4에서 대화 1-2턴 추가
```

### 방법 B: API 직접 호출 (빠른 방법)

```bash
# 1. 회원가입
curl -X POST https://api.mamuri.app/api/auth/signup \
  -H "Content-Type: application/json" \
  -d '{
    "email": "reviewer@mamuri.app",
    "password": "Review2026!",
    "nickname": "리뷰어"
  }'

# 2. 로그인하여 토큰 받기
TOKEN=$(curl -s -X POST https://api.mamuri.app/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"reviewer@mamuri.app","password":"Review2026!"}' \
  | jq -r '.data.accessToken')

# 3. 일기 작성 (5개 반복)
curl -X POST https://api.mamuri.app/api/diaries \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN" \
  -d '{
    "title": "좋은 하루였어요",
    "content": "오늘은 날씨가 정말 좋았어요...",
    "mood": "HAPPY"
  }'

# (나머지 일기도 동일 패턴으로 생성)
```

## 5. 데모 데이터 부족 시 위험

| 시나리오 | 위험도 | 결과 |
|---------|--------|------|
| 일기 0개 (빈 계정) | 🔴 높음 | 심사관이 핵심 기능(AI 답변)을 즉시 확인 불가 → "기능 불완전" 거절 가능 |
| 일기 1개만 | 🟠 중간 | AI 답변은 보이지만 캘린더/목록 기능이 빈약해 보임 |
| AI 답변 없는 일기만 | 🔴 높음 | 핵심 기능이 작동하지 않는 것처럼 보임 → 거절 가능 |
| 대화 기록 없음 | 🟡 낮음 | 심사관이 직접 테스트할 수 있지만, 미리 있으면 더 좋음 |
| 기본 설정만 | ✅ 안전 | 기본 설정으로도 앱이 정상 동작함. 심사관이 변경 테스트 가능 |
