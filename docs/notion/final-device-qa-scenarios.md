# 최종 디바이스 QA 시나리오 및 수동 테스트 런북

> 최종 업데이트: 2026-03-23
> 목적: 스토어 제출 전 실기기/시뮬레이터에서 수행해야 하는 수동 테스트 시나리오

---

## 테스트 환경 준비

### 필요 장비
- [ ] iPhone (iOS 15.1 이상) 또는 iOS 시뮬레이터
- [ ] Android 기기 또는 에뮬레이터
- [ ] Wi-Fi + 셀룰러 네트워크 (네트워크 전환 테스트용)
- [ ] 테스트용 Google 계정
- [ ] 테스트용 Apple ID (iOS 테스트 시)

### 빌드 설치
```bash
# iOS 프로덕션 빌드
cd mobile && eas build --platform ios --profile production

# Android 프로덕션 빌드
cd mobile && eas build --platform android --profile production
```

### 테스트 순서 권장
```
1. 인증 (회원가입/로그인/소셜) — 가장 먼저
2. 일기 CRUD — 핵심 기능
3. AI 답변/대화 — 핵심 가치
4. AI 친구 설정 — 차별 기능
5. 설정/테마/언어 — 환경 설정
6. 동의/신고/법적 — 규정 준수
7. 계정 삭제 — 마지막에 (계정이 삭제되므로)
8. 에러/엣지 케이스 — 보충 테스트
```

## PART A: 핵심 기능 시나리오 (필수)

### A-01: 이메일 회원가입

| 항목 | 내용 |
|------|------|
| **목적** | 새 사용자가 이메일로 가입할 수 있는지 확인 |
| **사전조건** | 앱 첫 실행 상태 (로그아웃) |
| **심사 연관** | Apple/Google 모두 핵심 확인 |
| **실패 시 심각도** | 🔴 CRITICAL |

**테스트 절차:**
1. 앱 실행 → 로그인 화면 표시 확인
2. "회원가입" 링크 탭
3. 닉네임 입력: `테스터`
4. 이메일 입력: `test-qa@mamuri.app`
5. 비밀번호 입력: `Test1234!`
6. 비밀번호 확인 입력: `Test1234!`
7. AI 데이터 처리 동의 체크박스 탭 → 체크 상태 확인
8. "시작하기" 버튼 탭

**예상 결과:**
- 비밀번호 강도 표시가 업데이트됨 (약함→보통→좋음→강함)
- AI 동의 체크 전 "시작하기" 버튼 비활성화
- AI 동의 체크 후 "시작하기" 버튼 활성화
- 가입 성공 → AI 친구 설정 화면 또는 메인 화면으로 이동
- **PASS 기준**: 메인 화면에 도달하고, 닉네임이 표시됨

### A-02: 이메일 로그인

| 항목 | 내용 |
|------|------|
| **목적** | 기존 계정으로 로그인 가능 확인 |
| **사전조건** | A-01에서 생성한 계정 존재 |
| **심사 연관** | 데모 계정 로그인 테스트 |
| **실패 시 심각도** | 🔴 CRITICAL |

**테스트 절차:**
1. 로그인 화면에서 이메일/비밀번호 입력
2. "로그인" 버튼 탭
3. 잘못된 비밀번호로 시도 → 에러 메시지 확인
4. 올바른 비밀번호로 시도 → 로그인 성공 확인

**예상 결과:**
- 잘못된 비밀번호: "이메일 또는 비밀번호를 확인해주세요" 메시지 표시
- 올바른 비밀번호: 메인 화면(일기 목록)으로 이동
- **PASS 기준**: 로그인 성공, 기존 일기 목록 표시

### A-03: Google 로그인

| 항목 | 내용 |
|------|------|
| **목적** | Google 소셜 로그인 동작 확인 |
| **사전조건** | Google 계정 보유, 프로덕션 빌드 (Expo Go 불가) |
| **심사 연관** | Apple은 Google 로그인이 있으면 Apple 로그인도 필수 |
| **실패 시 심각도** | 🟠 HIGH |

**테스트 절차:**
1. 로그인 화면에서 "Google로 로그인" 버튼 탭
2. Google 계정 선택 화면 표시 확인
3. 계정 선택 → 인증 진행
4. 첫 로그인: 닉네임 설정 화면으로 이동 확인
5. 닉네임 입력 + AI 동의 체크 → "시작하기"
6. 재로그인: 바로 메인 화면으로 이동 확인

**예상 결과:**
- Google 인증 팝업 정상 표시
- 첫 로그인 시 닉네임 설정 화면
- 재로그인 시 바로 메인 화면
- **PASS 기준**: 메인 화면 도달, 프로필에 닉네임 표시

### A-05: 일기 작성 + AI 답변

| 항목 | 내용 |
|------|------|
| **목적** | 핵심 기능 — 일기 작성 후 AI 답변 수신 확인 |
| **사전조건** | 로그인 상태 |
| **심사 연관** | 앱의 핵심 가치 확인 |
| **실패 시 심각도** | 🔴 CRITICAL |

**테스트 절차:**
1. 메인 화면에서 "+" 버튼 탭
2. 감정 선택: "행복해요" 탭
3. 제목 입력: `테스트 일기`
4. 내용 입력: `오늘은 날씨가 좋아서 기분이 좋았어요. 공원에서 산책하고 커피도 마셨어요.`
5. "저장" 버튼 탭
6. 로딩 후 일기 상세 화면 확인
7. AI 답변이 표시되는지 확인

**예상 결과:**
- 저장 후 일기 상세 화면으로 이동
- AI 친구의 답변이 2-5문장으로 표시
- 답변 톤: 따뜻하고 공감적 (설정에 따라)
- 감정 선택이 일기에 반영됨
- **PASS 기준**: AI 답변이 표시되고, 한국어이며, 공감적인 톤

> ⚠️ **중요**: AI 답변이 "오늘 하루도 정말 수고 많으셨어요..." (stub 응답)이면
> 프로덕션 서버의 AI_PROVIDER가 stub으로 설정된 것입니다.
> 반드시 실제 OpenAI 응답인지 확인하세요.

### A-06: AI 대화 이어가기

| 항목 | 내용 |
|------|------|
| **목적** | AI 답변에 대화를 이어갈 수 있는지 확인 |
| **사전조건** | A-05에서 AI 답변이 있는 일기 존재 |
| **실패 시 심각도** | 🟠 HIGH |

**테스트 절차:**
1. AI 답변이 있는 일기 상세 화면에서
2. 하단 입력창에 "고마워, 위로가 됐어" 입력
3. 전송 버튼 탭
4. AI 후속 답변 확인
5. 한 번 더: "내일도 좋은 하루가 될까?" 입력 → 전송

**예상 결과:**
- 대화가 채팅 형태로 이어짐
- AI 후속 답변이 이전 맥락을 반영
- **PASS 기준**: 2턴 이상 대화가 자연스럽게 이어짐

### A-08: AI 친구 커스터마이징

| 항목 | 내용 |
|------|------|
| **목적** | AI 친구 이름/성격/말투 변경 확인 |
| **사전조건** | 로그인 상태 |
| **실패 시 심각도** | 🟡 MEDIUM |

**테스트 절차:**
1. 하단 탭에서 "AI 친구" 탭 선택
2. AI 친구 프로필 화면 확인 (이름, 성격, 말투)
3. 이름 "변경" 버튼 → 새 이름 입력 (예: "하늘이") → 저장
4. 성격 변경: "밝은" 선택
5. 말투 변경: "반말" 선택
6. 이름이 변경되었는지 확인
7. 새 일기 작성 → AI 답변이 변경된 톤/말투를 반영하는지 확인

**예상 결과:**
- 이름 변경 후 프로필에 새 이름 표시
- 새 일기의 AI 답변이 "밝은" 톤 + "반말"로 생성
- **PASS 기준**: 설정 변경이 AI 답변에 반영됨

### B-02: 개인정보처리방침 / 이용약관 접근

| 항목 | 내용 |
|------|------|
| **목적** | 법적 문서 접근 가능 확인 |
| **사전조건** | 로그인 상태 |

### B-03: 계정 삭제 (마지막에 테스트)

| 항목 | 내용 |
|------|------|
| **목적** | Apple 5.1.1(v) / Google 정책 — 계정 삭제 기능 확인 |
| **사전조건** | 이메일 계정으로 로그인 상태 |
| **심사 연관** | 양쪽 스토어 필수 |
| **실패 시 심각도** | 🔴 CRITICAL |

> ⚠️ **주의**: 이 테스트는 실제로 계정을 삭제합니다. 테스트 전용 계정으로 수행하세요.

**테스트 절차:**
1. 설정 → "계정 삭제" 버튼 탭
2. **1단계 (경고)**: 삭제될 데이터 목록 표시 확인
   - 일기, AI 답변, 대화 기록, 설정 등
   - "되돌릴 수 없습니다" 경고
3. "다음" 탭
4. **2단계 (이유 선택)**: 6가지 사유 중 하나 선택
   - 낮은 사용률 / 다른 앱 / 개인정보 / AI 품질 / 사용성 / 기타
   - "기타" 선택 시 상세 입력 필드 표시
5. "다음" 탭
6. **3단계 (본인 확인)**: 비밀번호 입력
7. "계정 삭제" 버튼 탭
8. 삭제 완료 → 로그인 화면으로 이동

**예상 결과:**
- 3단계 플로우 정상 표시
- 비밀번호 틀리면 에러 메시지
- 삭제 후 로그인 화면
- 삭제된 계정으로 재로그인 시 실패
- **PASS 기준**: 전체 플로우 완료, 로그인 화면 도달, 재로그인 실패

3. 일기 목록/상세 화면에서 크기 반영 확인
4. 글꼴 → "명조" 선택 → 폰트 변경 확인
5. 기본값으로 복귀

**PASS 기준**: 크기/폰트 변경이 미리보기 및 실제 화면에 반영
