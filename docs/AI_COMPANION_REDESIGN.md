## 1. 기억 시스템 3계층 아키텍처

### 1.1 계층 구조

| 계층 | 유지 기간 | 내용 | 추출 | decay |
|------|----------|------|------|-------|
| 단기 | 7일 | 최근 일기 요약, 대화 키포인트, 오늘의 감정 | 실시간 | 7일 후 삭제/승격 |
| 중기 | 2~4주 | 주간 감정 패턴, 진행 중 이벤트, 최근 관심사 | 주간 리포트 시 | 4주 후 아카이브 |
| 장기 | 영구 | 성격, 핵심 관계, 인생 이벤트, 반복 주제, 가치관 | LLM 주간 배치 정제 | 없음 |

### 1.2 기억 타입 8종 (기존 3종 → 확장)

| 타입 | 설명 | 계층 |
|------|------|------|
| PERSON | 주변 인물 관계 | 장기 |
| INTEREST | 관심사/취미 | 장기→중기 |
| EVENT | 중요 이벤트 | 장기 |
| EMOTION_PATTERN (신규) | 감정 패턴 | 중기 |
| PREFERENCE (신규) | 사용자 선호 | 장기 |
| GROWTH (신규) | 성장/변화 지점 | 장기 |
| CONTEXT (신규) | 상황 맥락 | 단기 |
| SENSITIVE (신규) | 민감 주제 | 장기 |

### 1.3 기억 Decay 알고리즘

```
decayScore = baseImportance
             × recencyFactor(daysSinceLastReference)
             × frequencyFactor(mentionCount)
             × emotionalWeight(memoryType)

승격 조건:
  단기→중기: mentionCount >= 2 AND daysSinceCreated >= 3
  중기→장기: mentionCount >= 5 OR importance >= 4 OR type ∈ {PERSON, EVENT, SENSITIVE}

아카이브 조건:
  decayScore < 0.2 AND memoryTier != LONG_TERM
```

### 1.4 프롬프트 주입 방식 (계층별 분리)

```
[{{userName}}에 대해 내가 잘 아는 것들] ← 장기 기억
[요즘 {{userName}}의 상황] ← 중기 기억
[오늘 알게 된 것] ← 단기 기억
[주의사항] ← SENSITIVE 타입
```

## 2. 관계 발전 모델 (7단계)

| 단계 | 이름 | 양적 조건 | 질적 조건 | AI 톤 |
|------|------|----------|----------|-------|
| 1 | 첫 만남 | 기본 | - | 공손, 조심스러움 |
| 2 | 알아가는 중 | 일기 5+, 7일+ | - | 이름 자연스럽게 사용 |
| 3 | 관심과 기억 | 일기 12+, 대화 10+, 21일+ | 기억 3+ | 기억 적극 활용 |
| 4 | 편안한 친구 | 일기 25+, 대화 30+, 60일+ | 감정 다양성 4+, 자기노출 2+ | 가벼운 유머 허용 |
| 5 | 깊은 신뢰 | 일기 40+, 대화 60+, 120일+ | 민감 기억 존재, 강도 4+ 일기 5+ | 진심 어린 조언 |
| 6 | 든든한 동반자 | 일기 60+, 대화 100+, 180일+ | 성장 기억 3+, 리포트 열람 5+ | 장기 서사 연결 |
| 7 | 소울메이트 | 일기 100+, 대화 200+, 365일+ | 위기 극복 이력, 감정 다양성 7+ | 완전한 맥락 이해 |

### 관계 후퇴 메커니즘

- 30일 미사용 → 1단계 하락 (최소 2단계까지)
- 60일 미사용 → 2단계 하락 (최소 1단계까지)
- 기억은 유지, 톤만 조심스럽게 조정
- 복귀 시 기존 단계의 70% 조건만 충족하면 빠른 회복

## 3. 프롬프트 v6 구조

```
① 시스템 정체성 (고정)
② 관계 행동 가이드 (단계별 동적)
③ 기억 컨텍스트 (3계층 분리)
④ 감정 컨텍스트 (스티커 패턴 + 불일치 감지)
⑤ 멀티모달 컨텍스트 (사진 메타 + 꾸미기 패턴)
⑥ 행동 규칙 (안전 + 관계 단계별)
⑦ 오늘의 일기 (입력)
⑧ 출력 형식 (comment + followup + detectedEmotion + insightHint + referencedMemories)
```

### 출력 형식 확장

```json
{
  "comment": "공감 코멘트",
  "followupQuestion": "후속 질문",
  "detectedEmotion": "감지된 감정",
  "insightHint": "패턴/인사이트 (리포트용, nullable)",
  "referencedMemories": [42, 15]
}
```

## 4. 멀티모달 컨텍스트 이해

### 스티커 패턴 해석

| 패턴 | 해석 | AI 반응 |
|------|------|---------|
| 매일 같은 스티커 | 감정 고착 | "비슷한 감정이 이어지고 있네요" |
| 텍스트↔스티커 불일치 | 표현 못한 감정 | "사실 좀 복잡한 마음이었나요?" |
| 감정 급변 | 중요 사건 | "분위기가 많이 달라졌어요" |
| 강도 지속 하락 | 번아웃 신호 | 부드러운 체크인 |

### 사진 컨텍스트 (Phase 1: 메타데이터 기반)

- 촬영 시간대, 사진 수, 유무 패턴

## 5. 재참여 시스템

### 부재 단계별 AI 반응

| 부재 기간 | 반응 | 핵심 |
|----------|------|------|
| 1~2일 | 시간대별 인사 | 정상 |
| 3~6일 | 부드러운 체크인 + 진행 중 이벤트 | 기억 활용 |
| 7~13일 | 따뜻한 환영 + 마지막 감정 연결 | 죄책감 금지 |
| 14~29일 | 조심스러운 재연결 | "부담 없이" |
| 30일+ | 새로운 시작 + 관계 1단계 하락 | 기억 있되 과하지 않게 |

## 6. 안전 시스템 확장

### 3계층 안전 검사

| Layer | 방식 | 내용 |
|-------|------|------|
| 1 | 텍스트 키워드 (기존) | 위기 키워드 감지 |
| 2 | 감정 패턴 (신규) | 연속 부정 감정, 강도 하락 추적 |
| 3 | 기억 기반 맥락 (신규) | SENSITIVE 기억 + 현재 감정 교차 |

### 기억 안전 가드레일

- 자해/자살 방법, 폭력적 의도, 불법 활동 상세 → 기억 저장 금지
- 사용자는 모든 기억 열람/삭제 가능 (hard delete)
- SENSITIVE 기억 참조 시 반드시 조심스럽게 접근
