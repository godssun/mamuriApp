# Mamuri 3.0 — 리텐션 & 그로스 전략

> 작성일: 2026-03-27
> 담당: 리텐션/그로스 디자이너

---

## 1. 핵심 가설

**"감정 기록은 습관이 아니라 의식(ritual)이 되어야 한다"**

- 스티커 1탭 = 기록 완성 (진입 장벽 제로)
- AI 컴패니언 즉각 반응 = 감정 보상
- 캘린더 채워짐 = 시각적 성취 → 이탈 방지

---

## 2. 리텐션 루프

### 일일 루프

```
시간대별 AI 알림 → 홈 오픈 → 스티커 탭 → (선택: 사진/텍스트/꾸미기)
→ AI 응답 → 캘린더 스티커 반영 → 시각적 보상
```

**핵심**: 스티커 1개만 선택해도 스트릭 유지 + 캘린더 채워짐

### 주간 루프

```
주간 감정 리포트 도착 → AI 서술형 해석 → 패턴 발견 →
컴패니언 주간 회고 대화 → "이번 주는 이런 흐름이었어요"
```

### 월간 루프

```
월간 리포트 → 감정 변화 추이 → "한 달 전의 나" →
캘린더 완성도 시각화 → (선택: 공유 카드)
```

### 재방문 루프

| 부재 기간 | 알림 톤 | 핵심 메시지 |
|----------|---------|------------|
| 3일 | 부드러운 | "오늘 스티커 하나만 남겨볼까요?" |
| 7일 | 따뜻한 | "보고 싶었어요. 오늘은 어때요?" |
| 14일 | 조심스러운 | "부담 없이, 한 줄이라도 괜찮아요" |
| 30일+ | 환영 | "다시 만나서 반가워요!" |

**원칙**: 죄책감 유발 금지. 빈 날짜 부드럽게 처리.

## 3. 스트릭 재설계

### 현재 → 변경

| 현재 | 변경 |
|------|------|
| 텍스트 일기 저장 시에만 카운트 | 스티커 1개 선택만으로 유지 |
| 끊기면 0부터 | 월 1회 복구권 (프리미엄) |

### 스티커/테마 언락 보상

| 조건 | 보상 |
|------|------|
| 7일 연속 | 특별 스티커 1개 언락 |
| 30일 연속 | 계절 테마 언락 |
| 레벨업 | 레벨별 데코 스티커 팩 |

## 4. 푸시 알림 전략

| 타입 | 시간 | 내용 |
|------|------|------|
| 컴패니언 인사 | 20~21시 | 이전 감정 기억 기반 개인화 |
| 스트릭 위기 | 22시 | "스티커 하나만 남겨볼까요?" |
| 인사이트 도착 | 주간 리포트 시 | "감정 리포트가 도착했어요" |
| 기억 소환 | 월 1회 | "한 달 전 오늘, 이런 스티커를 선택했어요" |

## 5. 프리미엄 전환 전략

### 티어 구조

| 티어 | 핵심 혜택 |
|------|----------|
| FREE | 스티커+사진 무제한, AI 코멘트 무제한, AI 대화 3회/일 |
| DELUXE | AI 대화 20회/일, 주간/월간 AI 리포트, 추가 스티커 팩 |
| PREMIUM | AI 대화 무제한, 장기 메모리, 연간 리포트, 모든 스티커 |

### 전환 트리거

| 트리거 | 타이밍 | 전환 유형 |
|--------|--------|----------|
| 30일 스트릭 | 기록 직후 | 감정적 ("여기까지 왔는데") |
| 메모리 한도 | 기억 축적 시 | 기능적 ("더 기억하고 싶대요") |
| 시즌 스티커 | 계절 변경 시 | FOMO |
| 리포트 3회 | 리포트 열람 후 | 가치 확인 |

| 실험 | 가설 | 측정 |
